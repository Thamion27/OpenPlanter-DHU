# DHU CIB-8 Orchestrator

**CIB-8** is the DHU Eight-Layer Agentic Investigation Orchestrator.

It turns OpenPlanter-DHU into a lawful command system that can deploy, supervise, fuse, and audit specialized investigation agents across eight intelligence layers.

## Prime Directive

CIB-8 does not collect secrets unlawfully. It collects lawful signals, grades evidence, protects dignity, and produces evidence-backed decisions.

## Eight Layers

1. HUMINT Agent — lawful human insight, interviews, surveys, stakeholder reality.
2. OSINT Agent — public records, web, media, documents, public social signals.
3. FININT Agent — money flows, pricing, public contracts, incentives, revenue logic.
4. CYBINT Agent — defensive cyber risk, public advisories, owned/authorized asset review.
5. GEOINT Agent — location, territory, demographics, service areas, terrain/context.
6. IMINT Agent — public visual evidence, screenshots, images, videos, map imagery.
7. SIGINT-Safe Agent — public/owned communication patterns, narrative shifts, engagement signals.
8. MASINT Agent — measurable signatures, metrics, logs, timestamps, anomalies, baselines.

## Command Flow

```text
Mission Brief
  -> CIB Orchestrator
  -> Layer Agent Deployment
  -> Evidence Return Packets
  -> Evidence Fusion
  -> Red-Team QC
  -> Final Dossier
  -> After-Action Hindsight Skills
```
